# Capture method and continuity checks

The factual run is executed once by the unmodified Python Workshop. Every
Ed25519 receipt is verified before export. Production snapshots contain only
public state/events and complete public signed records; no private keys or tokens.

The read-only production stage imports the existing World components and the
existing reducer. It changes only framing, shadow casting and presentation time.
No protocol code, application route or implementation file is edited. All shot
classifications are retained in SHOTS.json, EDITS.json and render manifests.

Actors and existing marks settle before each take. New state changes animate
only when their corresponding real recorded state is supplied. The automatic
RAF loop is suppressed for controlled captures, and the original frame callbacks
receive the exact 1/24-second delta. Performance time advances by the same amount.
This avoids the software renderer's realtime cadence and double-clock behavior.
Keyframe reports retain worker positions, facts, shot state and frame number.
The transparent town canvas is cleared to its original cream body color before
JPEG export, so its real background is preserved instead of flattening to black.
Existing Town duplicate-key warnings and Three deprecation warnings are recorded
as inherited console warnings; they are distinct from page exceptions.

The full-frame close-ups of blank and stamped tickets, and the stationary
checkpoint insert, use the same original meshes. The workers in those shots are
outside the frame. Their original capture did not require an actor pose to prove
the shown object; it retains the fixed camera timing and genuine history state.

The actual receipt UI is replayed with the exact saved public projection from
step 6, before Juniper arrives. Only the two receipts that already existed then
are visible. Complete three-receipt evidence is retained separately. The UI's
built-in truncated signature display is not presented as the whole signed record.
The proof composition promotes literal decision/action/reason fields and retains
actual UI pixels, labeled as a recorded local project-notes fixture.

The bench occludes the checkpoint pieces from above. A low-angle insert makes
them visible without moving them or inventing work. Three marks belong to the
receipt ticket; two brass pieces belong to executed synthetic notes checkpoints.

Portrait uses shot-specific crops and re-typeset proof/end artwork. Its new-grant
shot preserves the entire owner-to-worker link in a wide inset instead of dropping
an endpoint. This is an adaptation of the master, with no new factual scenario.

Editorial trim points snap to the native 24-fps frame grid. Each segment is
encoded with an explicit frame count; cached parts are checked for that count
before concatenation. Audio uses the same snapped trim points. This prevents
fractional seeks from dropping a frame and shifting the subsequent cut's cue.
